# 聚餐費用分攤與預算計算機 (Dinner Expense & Budget Calculator)

這是一個基於 Python 的基礎資料處理與計算練習專案（Jupyter Notebook 格式）。程式旨在模擬真實情境中未經整理的字串資料，透過字串清理、資料型別轉換、算術運算與布林邏輯判斷，精準計算聚餐的應付總額、每人分攤費用，並評估是否超出個人預算。

## ✨ 核心功能

1. **字串資料清理 (Data Cleaning)**：
   * 移除聚餐名稱前後多餘的空白，並統一轉換為小寫格式。
   * 過濾餐費字串中的貨幣符號（`NT$`）、千分位逗號（`,`）與多餘空格。
2. **資料型別轉換 (Type Casting)**：
   * 將清理後的餐費字串轉換為浮點數（`float`）。
   * 將分攤人數字串轉換為整數（`int`）。
3. **費用與分攤計算 (Financial Calculation)**：
   * 依據原始餐費計算 $10\%$ 服務費，並扣除折價券金額得出應付總額。
   * 計算平均每人需分攤的費用。
4. **預算判斷 (Budget Evaluation)**：
   * 使用比較運算子判斷每人平均費用是否嚴格大於每人預算（等於預算時不算超過），並將結果儲存為布林值（`bool`）。
5. **格式化輸出 (Formatted Output)**：
   * 使用 Python `f-string` 將所有金額統一格式化至小數點後兩位輸出。

## 🧪 測試案例說明

本 Notebook 內含三個不同的情境測試區塊（Cells），用以驗證程式在不同參數下的運作結果：

| 測試區塊 | 原始餐費 | 服務費 ($10\%$) | 折價券 | 應付總額 | 分攤人數 | 每人費用 | 每人預算 | 是否超過預算 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Cell 1 (預設情境)** | $1200.00$ | $120.00$ | $100.00$ | $1220.00$ | $4$ 人 | $305.00$ | $300.00$ | `True` |
| **Cell 2 (增加人數)** | $1200.00$ | $120.00$ | $100.00$ | $1220.00$ | $5$ 人 | $244.00$ | $300.00$ | `False` |
| **Cell 3 (提高折扣)** | $1200.00$ | $120.00$ | $220.00$ | $1100.00$ | $4$ 人 | $275.00$ | $300.00$ | `False` |

## 🚀 如何執行

### 方法一：使用 Google Colab（推薦）
1. 開啟 [Google Colab](https://colab.research.google.com/)。
2. 上傳此 `.ipynb` 檔案。
3. 點擊各程式碼區塊左側的「執行」按鈕（或按下 `Shift + Enter`）即可查看輸出結果。

### 方法二：本機環境執行
1. 確保您的電腦已安裝 Python 3 與 Jupyter Notebook 或 JupyterLab。
2. 在終端機中啟動 Jupyter：
   ```bash
   jupyter notebook
   ```
3. 在瀏覽器介面中開啟此 `.ipynb` 檔案並依序執行儲存格。
